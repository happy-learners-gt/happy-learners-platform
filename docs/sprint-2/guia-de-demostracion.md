# Demostración de cinco minutos

Usa una ventana normal para el educador y una privada para el estudiante. No uses información personal. La demostración empieza en [producción](https://happy-learners-demo.lfmendoza-alvarez.workers.dev).

| Tiempo | Acción | Resultado que debe verse |
| --- | --- | --- |
| 0:00–0:40 | Entrar como `educador-demo`. Mostrar **Inicio**. | Continuar trabajando, próximas clases y estado de las lecciones en una sola vista. |
| 0:40–1:20 | Abrir **Cursos → Exploradores → Contenido**. | Unidades y lecciones en un solo outline, con estado y menú de acciones. |
| 1:20–2:30 | Abrir una lección. Editar una actividad y mostrar “Guardado”. En otra ventana, abrir la misma lección. | Autosave visible y edición colaborativa del texto con presencia. |
| 2:30–3:15 | **Vista previa** y **Publicar cambios**. | El estudiante solo ve lo publicado; el estado vuelve a “Publicada”. |
| 3:15–4:05 | Abrir el enlace en móvil y completar la lección. | Una actividad a la vez, avance visible y cierre claro, sin cuenta. |
| 4:05–5:00 | Abrir **Grupos → Registrar clase** y guardar la asistencia. | Grupo → clase → asistencia, con confirmación inmediata. |

El enlace estable de muestra es [Greetings and Introductions](https://happy-learners-demo.lfmendoza-alvarez.workers.dev/aprender/GREETINGS). El código es `GREETINGS`.

Para mostrar permisos, entra después como `admin-demo`: puede configurar la organización y administrar las cuentas existentes, pero la edición educativa y las listas de asistencia pertenecen al rol Educador.
