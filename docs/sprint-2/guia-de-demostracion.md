# Demostración de cinco minutos

Usa una ventana normal para el educador y una privada para el estudiante. No uses información personal. La demostración empieza en [producción](https://happy-learners-demo.lfmendoza-alvarez.workers.dev).

| Tiempo | Acción | Resultado que debe verse |
| --- | --- | --- |
| 0:00–0:40 | Entrar como `educador-demo` y abrir **Mis cursos**. | El curso reúne preparación, materiales, lecciones y operación de clase. |
| 0:40–1:20 | Abrir **Materiales**, buscar “Greetings” y editar un recurso. | Clasificación, búsqueda, edición y guardado en el contexto del curso. |
| 1:20–2:00 | Abrir **Preparar** y recorrer las unidades ordenadas. | La secuencia pertenece al curso y puede representar temas o semanas. |
| 2:00–3:15 | Abrir **Materiales** y previsualizar un documento de clase. En otra ventana, abrir la misma lección para mostrar presencia y edición colaborativa del texto. | Los archivos permanecen privados y el contenido compartido se sincroniza entre educadores. |
| 3:15–4:05 | Abrir **Editar lecciones**. Mostrar el texto enriquecido, una actividad vinculada y una pregunta. Guardar y publicar. | El educador prepara una clase en una secuencia de actividades. |
| 4:05–5:00 | Abrir el enlace en móvil y completar la lección; después mostrar **Asistencia**. | El estudiante ve solo la revisión publicada, sin iniciar sesión; la lista queda dentro del curso. |

El enlace estable de muestra es [Greetings and Introductions](https://happy-learners-demo.lfmendoza-alvarez.workers.dev/?code=GREETINGS). El código es `GREETINGS`.

Para mostrar permisos, entra después como `admin-demo`: puede configurar la organización y administrar las cuentas existentes, pero la edición educativa y las listas de asistencia pertenecen al rol Educador.
