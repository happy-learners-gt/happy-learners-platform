# Demostración de cinco minutos

Usa una ventana normal para el educador y una privada para el estudiante. No uses información personal. La demostración empieza en [producción](https://happy-learners-demo.lfmendoza-alvarez.workers.dev).

| Tiempo | Acción | Resultado que debe verse |
| --- | --- | --- |
| 0:00–0:45 | Entrar como `educador-demo`. Abrir Preparar contenido. | Recursos, Niveles y unidades, Lecciones. Sin administración de permisos. |
| 0:45–1:30 | Buscar “Greetings”. Editar la descripción de un recurso sintético y guardar. | Búsqueda, edición y fecha de actualización. |
| 1:30–2:15 | Abrir Beginner → Greetings. Mostrar los botones de orden. | Un currículo con nombres claros y unidades dentro de un nivel. |
| 2:15–3:15 | Editar Greetings and Introductions. Mostrar texto, recurso y pregunta. Guardar un cambio breve. | El borrador cambia; la revisión pública anterior permanece. |
| 3:15–4:15 | Seleccionar Republicar. Abrir el enlace en la ventana privada o en el teléfono. | La revisión aumenta. Se ve el material y se puede responder a la pregunta. |
| 4:15–5:00 | Elegir “Terminé la lección”. Recargar la lista del educador. Cerrar sesión. | Aumenta el conteo agregado y la sesión se revoca. |

El enlace estable de muestra es [Greetings and Introductions](https://happy-learners-demo.lfmendoza-alvarez.workers.dev/?code=GREETINGS). El código es `GREETINGS`.

Para mostrar permisos, entra después como `admin-demo`: puede configurar la organización y administrar las cuentas existentes, pero la edición educativa pertenece al rol Educador.
